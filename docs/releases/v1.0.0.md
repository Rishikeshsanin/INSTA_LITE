# INSTA_LITE v1.0.0 — First installable preview

**Instagram, without the scroll.** Keep your native inbox and reactions while redirecting distracting pages.

## Download

- `INSTA_LITE-extension-v1.0.0.zip`: installable extension, with `manifest.json` at the ZIP root.
- `INSTA_LITE-source-v1.0.0.zip`: reviewed source, docs and tests; excludes local hosting metadata and environment files.
- `INSTA_LITE-website-v1.0.0.zip`: companion website with its download links.

## Install

Extract the extension ZIP into a permanent folder. Open `chrome://extensions` or `edge://extensions`, enable Developer mode, select Load unpacked and choose that folder. Pin INSTA_LITE, open Messages and sign in directly on Instagram. Refresh existing Instagram tabs.

## Verification and limitations

Local logic, fixture workflows, accessibility and ZIP-integrity checks passed; see `docs/VERIFICATION.md`. Browser fixtures and mock Chrome APIs do not establish live-account compatibility. Complete `docs/ACCEPTANCE.md` before a wider release.

Read + React is a focus aid, not a security boundary. Shared inline previews and composer layouts can change. Desktop only; no extension-store listing yet. No credentials or message bodies are collected by the extension.

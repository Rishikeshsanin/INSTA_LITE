Download extension ↓

Version 1.0.0 · Unpacked extension

  1. 1

    Download & extract

    Download the ZIP and choose Extract All. Keep the extracted folder somewhere permanent.

  2. 2

    Open your extension settings

    Paste chrome://extensions or edge://extensions into your address bar. Turn on Developer mode.

  3. 3

    Load INSTA_LITE

    Choose Load unpacked and select the extracted folder containing manifest.json. Pin the extension for easy access.

  4. 4

    Open your messages

    Click the extension, then Open Messages. Log in on Instagram if needed. Refresh any Instagram tabs you already had open.

Before you open your inbox

A few good
questions.

Does this work with my personal account?

Yes. It works with the Instagram website you already use, including personal accounts. It doesn’t use a messaging API or connect through a separate account.

Will you see my password or messages?

The extension does not collect your credentials, transmit messages or store conversations. It modifies Instagram’s page layout locally. Instagram continues to handle your login and messages.

Can I still reply to people?

Yes, in Full Messaging mode. The default Read + React mode hides composers and blocks common send controls. It is a focus aid, not a security boundary; Instagram layout changes may require updates.

What about reels sent in my DMs?

Shared Instagram post and reel links are hidden by default, and their destination pages redirect to your inbox. Some inline previews may remain if Instagram changes its markup. Regular photo and video attachments can still appear.

Does it work on my phone?

This release is for desktop Chrome and Edge. It does not modify the Instagram mobile app, and it cannot run in Chrome on iPhone.

Can I turn it off?

Yes. Turn off the distraction blocker in the extension popup to use Instagram normally. You can also disable or remove INSTA_LITE from your browser’s extension settings.

Is it ready for the Chrome Web Store?

This is a complete installable first release. Store publication is a separate step with store review. Real-account testing is still needed across Instagram layouts and languages before a wider release.

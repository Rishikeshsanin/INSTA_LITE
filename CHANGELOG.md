# Changelog

## 1.0.0 — 2026-10-03

First installable preview for desktop Chrome and Edge.

### Added

- Browser-level redirects for feed, Reels, Explore, stories, posts and profile detours.
- Authentication, two-factor, challenge and recovery route exceptions.
- Read + React and Full Messaging modes, with native Instagram reactions.
- Shared-post/reel link hiding, dynamic composer detection and SPA navigation guard.
- Local preferences, active inbox time, redirected-visit counters and 30-day history.
- Persistent 15/25/45-minute timer, badge and inbox completion reminder.
- Light/dark/system appearance, accessible settings and confirmed counter reset.
- Responsive companion website, fictional interactive demo, privacy page and installation guide.
- Versioned extension/source/website ZIPs; no runtime app dependencies.
- Unit, browser-fixture, accessibility and packaging checks; contribution and issue templates.

### Known limits

Live logged-in Instagram compatibility remains pending. DOM-based composer/link hiding can vary with language, account layout and Instagram updates. This does not modify the Instagram mobile app and is not yet published in extension stores.
